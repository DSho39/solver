# Mcds Plugin

Mcdsは、Minecraftサーバー（Bukkit/Spigot）向けのシンプルなプラグインです。プレイヤー向けのいくつかのお遊びコマンドや、ログインメッセージのカスタマイズ機能、ルートテーブルを利用したチェストの生成機能が含まれています。

## 機能概要
* ユニークな演出を伴うメッセージ表示コマンド
* ランダムでアイテムがもらえるくじ引きコマンド
* 実行するたびにエンチャントレベルが上がるアイテム取得コマンド
* カスタムログインメッセージ機能
* 起動時のルートテーブル付きチェスト生成（テスト機能）

## コマンド一覧

| コマンド | 説明 |
| :--- | :--- |
| `/test` | コマンドの実行テスト用。プレイヤーにメッセージを返し、コンソールに実行ログを出力します。 |
| `/message <テキスト>` | 指定したテキストをアクションバーに表示します。同時に、画面中央に「鮭のムニエル ～そこら辺にいたエスカルゴを添えて～」というユニークなタイトルが表示されます。 |
| `/send00` | 「ダメージ増加（Sharpness）」のエンチャントが付与された「棒」を入手します。このコマンドを実行するたびに、付与されるエンチャントのレベルが倍増（2の累乗）していきます。※レベルのカウントはプレイヤーがログインするたびにリセットされます。 |
| `/kuji` | 運試しコマンドです。50%の確率で「TNT」または「ダイヤモンド」がインベントリに追加されます。 |

## イベント・自動処理

### プレイヤーログイン時の処理
プレイヤーがサーバーに参加した際、デフォルトのメッセージの代わりに以下の黄色いメッセージがサーバー全体に表示されます。
> `[プレイヤー名]がサーバーにログインしました`

### 起動時のチェスト生成処理
プラグインが有効化（起動）されてから1秒後（20 Tick後）に、`world` ワールド内の以下の座標にチェストが自動生成されます。
* **座標:** X: 74, Y: -60, Z: 52
* **内容:** このチェストを開けると、「村の武器鍛冶（`village_weaponsmith`）」のルートテーブルに基づいたアイテムがランダムに生成されます。
