Mcds Plugin
Minecraft (Paper 1.21.4) 向けの謎解きワールド用ヒント表示＆ログインメッセージ変更プラグインです。
プレイヤーがコマンドを使って謎解きのヒントを段階的に閲覧できる機能と、サーバー参加時のメッセージをカスタマイズする機能を提供します。

概要
謎解きワールドや脱出ゲームなどのイベントをMinecraft上で開催する際に便利なプラグインです。
ヒントは一覧からクリックするだけで簡単に閲覧でき、運営者は誰がどのヒントを見たのかをサーバーログから後で確認することができます。

前提条件
このプラグインを動作させるには、以下の環境が必要です。

サーバー: Paper 1.21.4 （またはそのフォーク）

Java: Java 21 以上

依存API: Paper API / Adventure API (Kyori) が内部で使用されています

機能
1. ヒント閲覧機能 (/hint コマンド)
プレイヤーが謎解きのヒントを確認できるコマンドです。

/hint

利用可能なヒントの一覧を表示します。

チャット欄に表示された一覧（例: /hint 1-1）をクリックするだけで、そのヒントを直接開くことができます。

/hint <キー> または /hint <謎番号> <ヒント番号>

指定したヒントの本文を表示します。（例: /hint 1-1 または /hint 1 1）

存在しないキーを入力した場合は、エラーメッセージとともに /hint で一覧を見るよう促します。

【運営向け機能】ヒントの閲覧ログ
プレイヤーがヒントを開くと、サーバーのコンソール（および logs/latest.log）に以下のように記録されます。

[hint] PlayerName -> 1-1

これにより、イベント終了後に「どのプレイヤーがどこで詰まっていたか」「どのヒントが多く見られていたか」を分析することができます。

2. ログインメッセージのカスタマイズ
プレイヤーがサーバーに参加した際のデフォルトメッセージ（xxx joined the gameなど）を、日本語のカスタムメッセージに変更します。

表示例: [黄色の文字] PlayerNameがサーバーにログインしました

カスタマイズ（ヒントの追加・編集方法）
ヒントの文章や謎の数は、設定ファイル（config.yml）ではなくソースコードに直接記述されています。
ヒントを追加・編集する場合は、Mcds.java 内の setupHints() メソッドを編集してプラグインを再ビルドしてください。

ヒント追加の例
Java
// 既存のヒントの下に put を追加するだけで新しいヒントが作れます。
hints.put("4-1", new String[]{
        "§8──────── §6§l謎4  ヒント1§r§8 ────────",
        "",
        "§fここにヒントの本文を書きます。",
        "§f複数行に分けることも可能です。",
        ""
});
LinkedHashMap を使用しているため、ソースコードに記述した順番通りに /hint の一覧に表示されます。

装飾コード（§6 や §l など）を使用して、テキストに色や太字を付けることができます。

権限 (Permissions)
このプラグインには特別なパーミッション（権限）は設定されていません。
サーバーに参加しているすべてのプレイヤーがデフォルトで /hint コマンドを使用可能です。

ビルド方法
このソースコードをプラグインとしてサーバーに導入するには、Maven や Gradle を使用してビルド（jarファイルの生成）を行う必要があります。

プロジェクトをビルドし、生成された Mcds-1.0.jar (ファイル名は設定に依存) を取得します。

サーバーの plugins フォルダに jarファイルを配置します。

サーバーを起動（または再起動）するとプラグインが読み込まれます。
